# flutter_screenutil_wasm

Fork independente de [flutter_screenutil 5.9.3](https://pub.dev/packages/flutter_screenutil/versions/5.9.3),
com percurso iterativo da árvore de Elements durante o redimensionamento em
Flutter Web Wasm. Não é uma versão oficial do projeto original.

A documentação atualizada está disponível em [inglês](README.md) e
[chinês](README_CN.md). Veja também o [exemplo executável](example/README.md).

Importe `package:flutter_screenutil_wasm/flutter_screenutil_wasm.dart` tanto
para a inicialização como para as extensões de tamanho. Não misture os dois
pacotes, pois cada um possui seu próprio singleton.
